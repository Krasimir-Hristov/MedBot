# MedBot (MedScan RAG)

Двуезична медицинска RAG платформа (Български <-> Гръцки) за обработка и анализ на онкологични досиета.

## Технологичен стек
- **Framework:** Next.js 16 (App Router, TypeScript, Tailwind CSS v4)
- **Database:** Neon Serverless PostgreSQL с `pgvector`
- **AI Provider:** OpenRouter (OpenAI SDK)
- **Библиотеки:** `browser-image-compression`, `react-markdown`, `remark-gfm`, `lucide-react`

## Стартиране локално
```bash
npm install
npm run dev
```

Отворете [http://localhost:3000](http://localhost:3000) в браузъра.
