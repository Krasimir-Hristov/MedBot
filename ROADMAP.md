# 🗺️ MedBot – План и Роудмап за изпълнение

MedBot е специализирана двуезична медицинска RAG платформа (Български 🇧🇬 <-> Гръцки 🇬🇷) за онкологично досие (~30 документа), съобразена с високи стандарти за сигурност, мобилна адаптивност и бързодействие.

---

## 🛠️ Инсталиран технологичен стек

- **Framework:** Next.js 16 (App Router, TypeScript, Tailwind CSS v4)
- **Database:** Neon Serverless PostgreSQL (`@neondatabase/serverless`) с `pgvector` & `JSONB`
- **ORM & Validation:** Drizzle ORM (`drizzle-orm`, `drizzle-kit`, `drizzle-zod`, `zod`)
- **AI Provider:** OpenRouter през OpenAI SDK (`openai`) с актуални модели:
  - OCR / Vision: `google/gemini-3.8-flash` (1M контекст)
  - Medical Reasoning / Chat: `deepseek/deepseek-v4.1-flash`
  - Embeddings: `openai/text-embedding-3-small` (1536 измерения)
  - Audio: Web Speech API (`el-GR` / `bg-BG`) + `openai/whisper-large-v3`
- **Client & Markdown:** `browser-image-compression`, `react-markdown`, `remark-gfm`, `lucide-react`
- **Styling Utilities:** `clsx`, `tailwind-merge`, `class-variance-authority`
- **Code Quality:** CodeRabbit автоматично ревю (`.coderabbit.yaml`)
